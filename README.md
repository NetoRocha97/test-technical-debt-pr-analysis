**ABSTRACT**

This repository contains the experimental package for a study focused on the analysis and characterization of technical debt (TD) in pull requests (PRs), with particular emphasis on test code in Apache Java projects.

The goal is to investigate how technical debt is discussed during pull-request reviews, including the objectives of pull requests, the types of suggestions made during code reviews, the reasons for rejecting suggestions, and the discussion of technical debt in test code.

The study analyzes 1,152 merged pull requests from 12 Apache Java repositories. A qualitative analysis was conducted using a subset of 289 pull requests, with the support of a Large Language Model (LLM) to classify pull-request discussions and identify relevant information.

The scripts and datasets are organized to support reproducibility, including pull-request data collection, LLM-based analysis, result validation, manual validation, dataset processing, and the generation of statistical reports for the research questions (RQs).

**Experimental Workflow**

The scripts support the following general workflow:

1. **Data collection**: Collect pull request information and related discussions from the target repositories.
2. **Dataset preparation**: Organize and prepare the collected data for analysis.
3. **LLM-based analysis**: Analyze pull request content and discussions using the defined prompts and output schemas.
4. **Validation**: Validate analysis outputs and prepare data for manual inspection and comparison.
5. **Dataset consolidation**: Combine the results from different processing subsets into a consolidated dataset.
6. **Statistical analysis**: Generate descriptive statistics and research-question-specific results.
7. **Result export**: Produce tables, spreadsheets, charts, and textual summaries for further inspection and reporting.

The exact execution order and dependencies should be followed according to the individual scripts and the analysis protocol.

**Technologies**

The experimental package primarily uses:

- **`Python`** — Data collection, processing, LLM analysis, validation, and statistical analysis.
- **`GitHub`** — Source of pull request information and discussions.
- **`OpenAI API`** — LLM-based analysis of pull request content.
- **`Matplotlib`** — Generation of statistical charts.
- **`CSV, JSON, and Excel`** — Storage, exchange, and inspection of datasets and results.

**Reproducibility**

To reproduce the analyses, ensure that the required Python dependencies, API credentials, and input datasets are available.

1. Clone the repository.
2. Install the required Python packages.
3. Configure the necessary API credentials using the configuration expected by the scripts.
4. Ensure that the input datasets are available in the expected directories.
5. Execute the scripts according to their dependencies and the documented analysis protocol.
6. Inspect the generated files in the results/ directory.

The scripts may depend on intermediate datasets produced by earlier stages. Therefore, running them in numerical order alone may not be sufficient for every analysis; consult the individual scripts before execution.
